# Модуль "Рамадан трекер"

Как устроены плагины ядра: [MODULES_DOCUMENTATION.md](../../MODULES_DOCUMENTATION.md). Функции этого модуля — в [docs/FUNCTIONS_CATALOG.md](../../docs/FUNCTIONS_CATALOG.md) (файлы `modules/ramadan_tracker/*`).

## 📋 Описание

Модуль для отслеживания религиозных практик во время Рамадана с системой призового фонда и автоматическими выплатами победителям. Пользователи отмечают выполнение зикров (утренних и вечерних), количество салаватов и место совершения таравиха, получают баллы и участвуют в розыгрыше призового фонда.

**Версия:** 1.0.0  
**Автор:** Custom Module

---

## ✨ Возможности

### Для пользователей

- **Отслеживание практик:**
  - Утренний зикр (100 раз)
  - Вечерний зикр (100 раз)
  - Салават (от 100 до 10000 в день)
  - Место совершения таравиха (мечеть/дом)

- **Система баллов:**
  - Утренний зикр: 10 баллов
  - Вечерний зикр: 10 баллов
  - Салават: 1 балл за каждые 100 (макс. 100 баллов/день)
  - Таравих в мечети: 20 баллов
  - Таравих дома: 10 баллов

- **Призовой фонд:**
  - Просмотр своего места в топе
  - Просмотр начисленной суммы выигрыша
  - Запрос на вывод средств через support-бота
  - Отслеживание статуса запроса

- **Статистика:**
  - Общее количество баллов
  - Текущее место в рейтинге
  - История выполнения практик

### Для администраторов

#### В Telegram-боте:
- Просмотр топа пользователей с баллами и суммами
- Ручной запуск распределения призового фонда
- Просмотр всех запросов на вывод средств
- Удаление запросов на вывод (кнопки ❌)
- Отметка запросов как выполненных (кнопки ✅)
- Прикрепление скриншота доказательства выплаты

#### В веб-панели:
- Просмотр статистики модуля
- Управление выплатами (страница `/payouts`)
- Удаление запросов на вывод
- Отметка запросов как выполненных

#### В support-боте:
- Автоматическое создание тикетов при запросе вывода
- Создание топиков в форуме поддержки
- Уведомления о новых запросах

## 🚀 Установка и настройка

### 1. Установка модуля

Модуль устанавливается автоматически при размещении в папке `modules/ramadan_tracker/`.

Структура файлов:
```
modules/ramadan_tracker/
├── __init__.py              # Метаданные модуля
├── bot_handlers.py          # Обработчики Telegram-бота
├── panel_routes.py          # Маршруты веб-панели
├── db_schema.py             # Схема базы данных
├── db_cleanup.py            # Очистка данных
├── settings_schema.py       # Настройки модуля
├── README.md                # Документация
└── templates/
    └── modules/
        └── ramadan_tracker/
            ├── index.html   # Главная страница статистики
            └── payouts.html # Страница выплат
```

### 2. Активация модуля

1. Перейдите в админ-панель бота
2. Откройте раздел "Модули"
3. Найдите "Ramadan Tracker" и нажмите "Включить"
4. Автоматически:
   - Создадутся все необходимые таблицы
   - Применится миграция базы данных
   - Добавится кнопка в главное меню
   - Зарегистрируются обработчики

### 3. Настройка призового фонда

В настройках модуля доступны параметры:

- **`prize_fund`** (по умолчанию: 1000.0)
  - Размер призового фонда в рублях
  - Автоматически распределяется между победителями

- **`winners_count`** (по умолчанию: 3)
  - Количество победителей, получающих выплаты
  - Фонд делится пропорционально баллам

- **`prize_shares`** (по умолчанию: "50,30,20")
  - Процентное распределение призового фонда
  - Формат: "доля1,доля2,доля3,..."
  - Пример: "50,30,20" = 1-е место 50%, 2-е 30%, 3-е 20%
  - Сумма долей должна быть 100

### 4. Настройка support-бота

Для работы запросов на вывод средств необходимо:

1. **Настроить support-бота:**
   - Settings → Support Bot Settings
   - Указать `support_bot_token`
   - Указать `support_bot_username`
   - Указать `support_forum_chat_id` (ID группы с форумами)

2. **Добавить support-бота в группу:**
   - Создать супергруппу с включенными Topics
   - Добавить support-бота в эту группу
   - Дать ему права на создание топиков

3. **Запустить support-бота:**
   - В админ-панели нажать "Start Support Bot"

1. Нажать "🤲 Салават"

**Таравих:**
1. Нажать "🕌 Таравих"

1. Нажать "🏆 Топ" в главном меню
2. Просмотреть рейтинг и свою позицию

4. Запрос отправится в support-бота
5. Дождаться обработки администратором

### Для администраторов

#### Просмотр топа (Telegram)

Команда: Нажать "🏆 Топ" → увидеть кнопку "👑 Админ панель"

Отображается:
- Топ-N пользователей с баллами
- Начисленные суммы
- Статус запросов на вывод (⏳ ожидание / ✅ выполнено)

#### Управление выплатами (Telegram)

**Просмотр запросов:**
```
"👑 Админ панель" → "💰 Выплаты"
```

**Удаление запроса:**
```
Нажать кнопку "❌ 1" (где 1 - номер в списке)
```
Запрос будет удален из базы данных.

**Отметка как выполнено:**
```
Нажать кнопку "✅ 1" (где 1 - номер в списке)
```
Появится выбор:
- "📎 С доказательством" - бот попросит прикрепить скриншот
- "✅ Без доказательства" - просто отметит как выполнено

После прикрепления скриншота:
- Сохраняется `proof_file_id` в базе
- Устанавливается `completed_at = CURRENT_TIMESTAMP`
- Запрос помечается как выполненный

#### Веб-панель

**Главная страница:** `/modules/ramadan_tracker/`
- Общая статистика
- Количество пользователей
- Общая сумма баллов

**Страница выплат:** `/modules/ramadan_tracker/payouts`
- Список всех запросов на вывод
- Статусы: "Ожидание" / "Выполнено"
- Действия: "Удалить" / "Выполнено"

**Действия:**
- **Удалить:** POST `/modules/ramadan_tracker/payouts/delete` с `withdrawal_id`
- **Выполнено:** POST `/modules/ramadan_tracker/payouts/complete` с `withdrawal_id`

#### Ручной запуск распределения

```
"👑 Админ панель" → "💎 Распределить фонд"
```

Принудительно запускает алгоритм распределения призового фонда:
1. Получает настройки (prize_fund, winners_count, shares)
2. Определяет топ-N пользователей по баллам
3. Рассчитывает доли для каждого победителя
4. Сохраняет в таблицу `ramadan_tracker_reward_users`
5. Отправляет уведомления победителям

## ⚙️ Алгоритм распределения призового фонда

### 1. Условия запуска

Автоматический запуск происходит:
- При первом открытии модуля любым пользователем
- Если еще не было распределения для текущего периода

Ручной запуск:
- Администратор нажимает "💎 Распределить фонд"

### 2. Алгоритм

```python
1. Получить настройки:
   - prize_fund (например, 1000.0)
   - winners_count (например, 3)
   - prize_shares (например, "50,30,20")

2. Получить топ-N пользователей по баллам:
   SELECT user_id, SUM(баллы) as score
   FROM ramadan_tracker_daily
   GROUP BY user_id
   ORDER BY score DESC
   LIMIT winners_count

3. Рассчитать доли:
   - Разделить prize_shares на проценты: [50, 30, 20]
   - Для каждого победителя:
     amount = (prize_fund * share / 100)

4. Сохранить результаты:
   - Создать период в ramadan_tracker_reward_periods
   - Для каждого победителя добавить в ramadan_tracker_reward_users

5. Отправить уведомления:
   - Каждому победителю отправить сообщение с суммой
   - Добавить кнопки для запроса вывода и поддержки
```

### 3. Пример расчета

**Настройки:**
- prize_fund = 1000 ₽
- winners_count = 3
- prize_shares = "50,30,20"

**Топ пользователей:**
1. User A: 450 баллов → 500 ₽ (50%)
2. User B: 300 баллов → 300 ₽ (30%)
3. User C: 150 баллов → 200 ₽ (20%)

## 🔧 Миграция базы данных

### Автоматическая миграция

Модуль автоматически проверяет структуру базы при загрузке и добавляет недостающие колонки.

**Файл:** `db_schema.py`

**Функция:** `SCHEMA_SQL()` - возвращает список SQL-statements:
1. Основная схема (CREATE TABLE IF NOT EXISTS)
2. Миграции (ALTER TABLE ADD COLUMN)

**Проверяемые колонки:**
- `ramadan_tracker_reward_users.completed_at`
- `ramadan_tracker_reward_users.proof_file_id`

**Логика:**
```python
1. Подключиться к database.db
2. Выполнить PRAGMA table_info(ramadan_tracker_reward_users)
3. Получить список существующих колонок
4. Если completed_at отсутствует → добавить ALTER TABLE
5. Если proof_file_id отсутствует → добавить ALTER TABLE
6. Вернуть список statements для выполнения
```

### Ручная миграция

Если нужно вручную добавить колонки:

```sql
ALTER TABLE ramadan_tracker_reward_users 
ADD COLUMN completed_at TIMESTAMP DEFAULT NULL;

ALTER TABLE ramadan_tracker_reward_users 
ADD COLUMN proof_file_id TEXT DEFAULT NULL;
```

## 🎨 Особенности реализации

### Proxy-based Blueprints

Модуль использует proxy-архитектуру для Flask blueprints:
- Blueprint не регистрируется напрямую в Flask app
- View-функции извлекаются и сохраняются в registry
- Главное приложение проксирует запросы к функциям

**Результат:**
- `url_for()` не работает → использовать hardcoded paths
- Редиректы: `redirect("/modules/ramadan_tracker/payouts")`

### FSM для вложенных диалогов

Модуль использует aiogram FSM для multi-step workflows:

**Состояние:** `WithdrawalStates.waiting_proof`

**Workflow:**
1. Админ нажимает "✅ 1" (отметить выполненным)
2. Бот предлагает "📎 С доказательством"
3. Переход в состояние waiting_proof
4. Админ отправляет фото
5. Бот сохраняет file_id и отмечает выполненным
6. Выход из состояния

### Support-bot Integration

**Создание тикета:**
1. Модуль записывает тикет в `support_tickets`
2. Создает временный инстанс support-бота
3. Создает топик в форуме через support-бота
4. Отправляет уведомление в топик
5. Закрывает сессию support-бота

**Требования:**
- `support_bot_token` должен быть настроен
- `support_forum_chat_id` должен указывать на супергруппу
- Support-бот должен быть добавлен в эту группу
- У бота должны быть права на создание топиков

- Используется `UNIQUE(user_id, date)` для быстрого поиска
- Индексы на ключевых колонках
- GROUP BY с агрегацией для расчета баллов
- LIMIT для топа пользователей

### Кэширование

Модуль не использует кэширование, так как:
- Данные изменяются часто
- Запросы простые и быстрые
- Количество пользователей ограничено

Если нужно добавить кэширование:
```python
from functools import lru_cache

@lru_cache(maxsize=100)
def _get_score(user_id: int) -> int:
    # ... запрос к БД
```

### Ограничения

- Максимум 10000 салаватов в день
- Один запрос на вывод одновременно
- Автоматическое распределение раз в период
