## Вход и доступ

### Веб-панель управления

**URL:** `http://your-domain:5000` или `http://your-ip:5000`

**Логин по умолчанию:**
- Логин: `admin`
- Пароль: `admin`

⚠️ **Важно:** Сразу после первого входа измените пароль в разделе "Панель" → "Пароль панели управления"

### Telegram Bot - админ панель

Для доступа к admin-панели в Telegram боте:
1. Запустите бота
2. Нажмите кнопку "Админ" (появляется только для администраторов)
3. Используйте меню "⚙️ Настройки"

## Панель управления (Web)

### Раздел "Панель"

#### Обязательные настройки:

**Логин панели управления**
- Имя пользователя для входа в веб-панель
- По умолчанию: `admin`

**Пароль панели управления**
- Храните пароль в надежном месте
- Рекомендуется использовать сложный пароль

**Название бренда (опционально)**
- Отображается в шапке панели
- Пример: "MyVPN Service"

#### Резервное копирование

**Интервал резервного копирования**
- Автоматическое создание резервных копий базы данных

- Копии сохраняются с временной меткой

**Восстановление из резервной копии**
- Выберите файл `*.db` 
- Нажмите "Восстановить"
- ⚠️ Текущая база будет заменена!

## Настройки основного бота

### Раздел "Бот" в веб-панели или "⚙️ Настройки" в Telegram

#### Обязательные настройки:

**Токен бота** *(обязательно)*
- Получить у [@BotFather](https://t.me/BotFather)
- Команда: `/newbot`
- Формат: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

**Username бота** *(обязательно)*
- Имя бота без символа `@`
- Пример: `myvpnbot`

**Telegram ID Администратора** *(обязательно)*
- Ваш Telegram ID
- Узнать можно у [@userinfobot](https://t.me/userinfobot)
- Можно указать несколько через запятую

#### Автозапуск:

**Автозапуск основного бота**
- ✅ Включено: бот запускается автоматически при старте панели
- ❌ Выключено: требуется ручной запуск

**Автозапуск support-бота**
- Аналогично основному боту
- Работает только при настроенном support-боте

#### Ссылки и контент:

**Ссылка на канал**
- URL вашего Telegram-канала
- Пример: `https://t.me/myvpnchannel`
- Отображается в разделе "Ссылки"

**Ссылка на чат**
- URL вашего Telegram-чата
- Пример: `https://t.me/myvpnchat`

**Принудительная подписка**
- ✅ Включено: пользователь должен подписаться на канал
- ❌ Выключено: подписка не требуется

**Текст под ссылками в главном меню**
- Промо-текст с описанием сервиса
- Поддерживает HTML-разметку Telegram
- Пример:
  ```
  🌐 Множество локаций
  🚀 Скорость серверов 1 Гбит/с
  📊 Безлимитный трафик
  
  Спасибо, что вы с нами!
  ```

#### Настройки карточки ключа:

**Показывать "Подключить устройство"**
- Кнопка для подключения ключа на устройстве
- Рекомендуется: ✅ Включено

**Показывать "Как использовать"**
- Кнопка с инструкциями по подключению
- Рекомендуется: ✅ Включено

#### Оплата:

**Запрашивать email перед оплатой**
- ✅ Включено: появляется шаг ввода email (можно пропустить)
- ❌ Выключено: сразу выбор способа оплаты

## Настройки Support-бота

### Раздел "Support-бот" в веб-панели

Support-бот обрабатывает обращения пользователей в техподдержку.

#### Обязательные настройки:

**Токен support-бота** *(обязательно)*
- Создайте отдельного бота у [@BotFather](https://t.me/BotFather)
- Формат: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

**Username support-бота**
- Имя бота без `@`
- Пример: `myvpnsupportbot`

**ID саппорт-чата (форум)**
- ID Telegram-группы с включенными темами (Topics)
- Каждый тикет создает отдельную тему в группе
- Опционально: можно оставить пустым

### Как получить ID форум-чата:

1. Создайте группу в Telegram
2. Включите "Темы" в настройках группы
3. Добавьте support-бота в группу
4. Сделайте бота администратором с правами управления темами
5. ID группы можно узнать через [@userinfobot](https://t.me/userinfobot) (переслав сообщение из группы)

## Хосты и тарифы

### Раздел "Хосты/Тарифы" в веб-панели или "🖥 Хосты" в Telegram

Управление VPN-серверами и тарифными планами.

### Добавление хоста

#### Через веб-панель:

1. Перейдите в раздел "Хосты/Тарифы"
2. Нажмите "Добавить хост"
3. Заполните поля

#### Через Telegram:

1. Откройте админ-панель
2. Перейдите в "⚙️ Настройки"
3. Выберите "🖥 Хосты"
4. Нажмите "➕ Добавить хост"

### Параметры хоста:

**Имя хоста** *(обязательно)*
- Уникальное название сервера
- Пример: `server-nl-1`, `france-01`

**URL панели Remnawave** *(обязательно)*
- Адрес панели управления сервером
- Формат: `https://panel.example.com`

**Remnawave API Token**
- Токен для доступа к API
- Получить в настройках Remnawave

**Remnawave Cookies** (опционально)
- JSON с cookies для авторизации
- Альтернатива токену

**Ссылка подписки**
- Шаблон URL подписки
- Пример: `https://server.com/sub/`

**Описание**
- Краткое описание сервера
- Пример: "VPN сервер в Амстердаме"

**Лимит трафика по умолчанию**
- В байтах или 0 для безлимита
- Применяется к новым ключам

**Стратегия лимита трафика**
- `NO_RESET` - не сбрасывается
- `RESET_MONTHLY` - сброс каждый месяц

**Активен**
- ✅ Хост доступен для создания ключей
- ❌ Хост скрыт от пользователей

### SSH настройки для Speedtest:

**SSH Host**
- IP или домен сервера
- Пример: `1.2.3.4` или `server.com`

**SSH Port**
- По умолчанию: `22`

**SSH User**
- Имя пользователя
- Обычно: `root`

**SSH Password**
- Пароль для подключения
- Можно оставить пустым при использовании ключа

**Путь к SSH ключу**
- Путь к файлу приватного ключа на сервере панели
- Пример: `/app/keys/id_rsa`

**Автоустановка Speedtest**
- Кнопка для автоматической установки speedtest-cli на сервер

### Управление тарифами:

Каждый хост может иметь несколько тарифных планов.

#### Параметры тарифа:

**Название** *(обязательно)*
- Название плана
- Пример: "1 месяц", "Полгода", "Год"

**Месяцев** *(обязательно)*
- Длительность подписки в месяцах
- Пример: `1`, `3`, `6`, `12`

**Цена** *(обязательно)*
- Стоимость в рублях
- Пример: `200`, `499.99`

**Длительность в днях** (опционально)
- Точная длительность в днях
- Переопределяет "месяцы"

**Лимит трафика** (опционально)
- В байтах или 0 для безлимита

**Лимит устройств (HWID)** (опционально)
- Максимум устройств
- 0 = без ограничений

**Активен**
- ✅ План отображается пользователям
- ❌ План скрыт

#### Действия с тарифом:

- **Редактировать** - изменить параметры
- **Удалить** - удалить тариф (❌)

## Реферальная программа

### Раздел "Рефералы" в веб-панели или "👥 Рефералка" в Telegram

Настройка системы привлечения пользователей.

### Основные настройки:

**Включить реферальную систему**
- ✅ Система активна
- ❌ Система выключена (рефералы не работают)

**Бонус +1 день к ключу пригласившему**
- ✅ Пригласивший получает +1 день при покупке реферала
- ❌ Бонус отключен

### Тип начисления вознаграждения:

Выберите один из трех вариантов:

#### 1️⃣ Процент с покупки реферала

Пригласивший получает процент от каждой покупки реферала.

**Процент вознаграждения**
- От 0 до 100%
- По умолчанию: `10%`
- Пример: при покупке на 500₽ реферер получит 50₽

**Когда применяется:**
- При каждой покупке приглашенного пользователя
- Начисляется на реферальный баланс

#### 2️⃣ Фиксированная сумма за покупку

Пригласивший получает фиксированную сумму за каждую покупку реферала.

**Фиксированная сумма**
- В рублях
- По умолчанию: `50₽`
- Пример: за любую покупку реферер получит 50₽

**Когда применяется:**
- При каждой покупке приглашенного пользователя
- Независимо от суммы покупки

#### 3️⃣ Стартовый бонус при регистрации

Пригласивший получает бонус сразу при старте бота реферал.

**Стартовый бонус**
- В рублях
- По умолчанию: `20₽`
- Начисляется один раз при первом запуске

**Когда применяется:**
- Когда новый пользователь запускает бота по реферальной ссылке
- Единоразово

### Дополнительные настройки:

**Скидка для нового пользователя**
- Процент скидки на первую покупку
- По умолчанию: `5%`
- Мотивирует к первой покупке

**Минимальная сумма для вывода**
- Минимум для вывода реферального баланса
- По умолчанию: `100₽`
- Защита от микровыводов

### Как пользователь получает реферальную ссылку:

1. Пользователь нажимает "💰 Рефералка" в боте
2. Получает реферальную ссылку
3. Делится ссылкой с друзьями
4. Отслеживает статистику и баланс

## Пробный период (Триал)

### Раздел "Триал" в веб-панели или "🎁 Триал" в Telegram

Бесплатный пробный период для новых пользователей.

### Настройки триала:

**Включить пробный период**
- ✅ Новые пользователи могут активировать триал
- ❌ Триал недоступен

**Длительность (в днях)**
- От 1 до 365 дней
- По умолчанию: `3 дня`
- Рекомендуется: 1-7 дней

**Лимит трафика (ГБ)**
- Максимум трафика на триал
- `0` = без лимита (безлимитный трафик)
- Пример: `1`, `5`, `10`

**Лимит устройств (HWID)**
- Максимум устройств на триал-ключ
- `0` = без лимита
- Рекомендуется: `1` или `2`

### Особенности:

- Триал доступен **один раз** для каждого пользователя
- После окончания триала пользователь может купить платную подписку
- Триал-ключ помечается тегом `trial` в базе данных
- Администраторы могут видеть триал-ключи отдельно

### Рекомендуемые настройки:

**Для тестирования сервиса:**
- Длительность: 3 дня
- Трафик: 5 ГБ
- Устройства: 1

**Для демонстрации:**
- Длительность: 1 день
- Трафик: 1 ГБ
- Устройства: 1

**Щедрый триал:**
- Длительность: 7 дней
- Трафик: без лимита (0)
- Устройства: 2

## Франшиза

### Раздел "Франшиза" в веб-панели или "💼 Франшиза" в Telegram

Система клонирования бота для партнеров.

### Основные настройки:

**Включить создание ботов пользователями**
- ✅ Пользователи видят кнопку "🤖 Создать бота"
- ❌ Кнопка скрыта для всех пользователей

**Процент комиссии для франшизников**
- Какой % от платежей получает владелец клона
- От 0 до 100%
- По умолчанию: `35%`
- Рекомендуется: 30-40%

**Минимум для вывода**
- Минимальная сумма для вывода заработка
- По умолчанию: `1500₽`
- Рекомендуется: 1000-3000₽

### Как работает франшиза:

1. **Пользователь создает бота:**
   - Нажимает "🤖 Создать бота"
   - Получает токен от [@BotFather](https://t.me/BotFather)
   - Вводит токен в панели
   - Получает свой клон бота

2. **Франшизник получает доход:**
   - Клиенты покупают подписки через его бота
   - От каждого платежа начисляется комиссия
   - Накопленные средства можно вывести

3. **Вывод средств:**
   - Франшизник добавляет реквизиты (банк + карта/телефон)
   - Создает заявку на вывод
   - Администратор обрабатывает заявку

### Управление франшизой (админ):

#### В веб-панели:

- Раздел "Франшиза" в главном меню
- Список всех созданных ботов
- Статистика по каждому боту
- Заявки на вывод средств

#### В Telegram:

- "💼 Франшиза" в админ-меню
- Просмотр ботов и их владельцев
- Обработка выплат

### Реквизиты для выплат:

Франшизник может указать:
- **Банк:** Сбербанк, Тинькофф, Альфа и т.д.
- **Тип реквизита:** Карта или телефон
- **Значение:** Номер карты или номер телефона
- **По умолчанию:** Один реквизит можно сделать основным

### Раздел "Капча" в Telegram (только в боте)

### Доступ к настройкам:

1. Админ-панель в Telegram
2. "⚙️ Настройки"
3. "🛡️ Капча"

### Настройки капчи:

**Включить капчу**
- ✅ Новые пользователи проходят капчу
- ❌ Капча отключена

**Тип капчи**
- `math` - Математический пример (3 + 5 = ?)
- `button` - Нажать правильную кнопку

**Максимум попыток**
- Количество попыток для прохождения
- По умолчанию: `3`

**Время на прохождение (минуты)**
- Срок действия капчи

**Текст сообщения капчи**
- Приветственное сообщение перед капчей
- По умолчанию: "👤 Привет! Ты выглядишь как бот. Пройди простую капчу..."

### Как работает капча:

1. Новый пользователь запускает бота
2. Видит сообщение с капчей
3. Вводит ответ (для math) или нажимает кнопку
4. При успехе - доступ к боту
5. При провале - новая попытка или блокировка

### Рекомендации:

- Включайте капчу при наличии спама
- Используйте `math` для лучшей защиты
- Не ставьте слишком короткое время
- 3 попытки обычно достаточно

### Типы меню:

**main** - Главное меню пользователя

- Основные функции бота

**admin** - Админ-меню
- Только для администраторов
- Управление ботом

### Создание кнопки:

1. Выберите тип меню
2. Нажмите "➕ Добавить кнопку"
3. Введите текст кнопки
4. Выберите действие:
   - **Callback** - действие внутри бота
   - **URL** - открыть ссылку

### Параметры кнопки:

**Текст кнопки**
- Что отображается на кнопке
- Поддержка emoji
- Пример: "🎁 Подарки"

**Callback Data**
- Команда для обработки
- Пример: `show_gifts`

**URL**
- Ссылка для открытия
- Пример: `https://example.com`

**Позиция**

- Колонка: позиция в ряду (0, 1, 2...)

- Сколько колонок занимает
- По умолчанию: `1`

**Активна**
- ✅ Кнопка отображается
- ❌ Кнопка скрыта

**Порядок сортировки**
- Чем меньше число, тем выше кнопка
- По умолчанию: `0`

### Управление кнопками:

- **Редактировать** - изменить параметры
- **Деактивировать** - скрыть кнопку
- **Удалить** - удалить кнопку навсегда

```

```

## Частые вопросы (FAQ)

### Бот не отвечает

**Проверьте:**
- Токен введен правильно
- Бот запущен (статус в панели)
- Нет конфликтов с другими ботами на том же токене

### Платежи не проходят

**Проверьте:**
- Правильность API ключей платежной системы
- Webhook настроен (для ЮKassa, TON)
- В логах панели нет ошибок

### Ключи не создаются

**Проверьте:**
- Хост активен и доступен
- Remnawave API токен действителен
- URL панели Remnawave правильный
- Есть хотя бы один тариф

### Реферальная система не работает

**Проверьте:**
- Реферальная система включена
- Выбран тип начисления
- Процент/сумма больше 0
